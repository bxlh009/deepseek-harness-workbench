# Agent Note：可见且可配置的视觉输入

状态：已实现

[English](2026-08-15-visible-vision-input-controls.md) | 中文

## 问题

Web 图片输入已经支持粘贴和整页拖放，但输入框没有可见的文件选择器。自定义 pi-ai 模型只能通过编辑 `settings.yaml` 声明 `input: [text, image]`，所以产品会提示用户切换视觉模型，却没有提供可操作的入口来把手动声明的模型标记为支持图片。

## 决策

输入框保留命令启动器，并增加独立图片选择按钮，支持 PNG、JPEG、WebP 和 GIF。所选文件进入现有草稿附件栏，因此继续使用既有的大小限制、持久上传、模型准入和重试行为。

每个自定义 pi-ai 模型行在高级选项中提供“支持图片输入”复选框。启用时把该行已有的 `input` 能力写为 `[text, image]`，禁用时写为 `[text]`。此项必须主动开启：模型名称不能证明能力，图片生成端点也不等于视觉理解端点。

## 后果

用户无需了解拖放或 YAML 就能发现图片输入，同时保守的纯文本默认值保持不变。勾选能力仍只是部署声明；最终以提供方行为为准，错误声明仍可能被拒绝。

## 测试

对话测试通过新选择器选取文件，并验证文件进入既有接收回调。模型设置测试在一行启用视觉、保持相邻行不变，并验证精确的设置变更。
