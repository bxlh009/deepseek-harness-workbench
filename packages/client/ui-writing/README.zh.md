# `@deepseek-ai/dsh-client-ui-writing`

[English](README.md) | 中文

写作页是一个本地优先的长篇编辑器，复用 Harness 的模型目录。用户必须明确选择提供方和模型；产品不会静默替换模型。正文支持实时显示本章与选区字数、引用选区、按选区改写和润色。生成内容先进入预览，只有用户确认后才写入正文。

作品、结构化故事记忆、章节、正文、助手对话和所选模型保存在浏览器本地存储中。结构化记忆包括世界规则、语义地图的地点与连接、人物档案、人物关系，并保留时间线和大纲。Markdown 导出是用户主动触发的本地下载。模型生成使用现有的单路由文本 `llm.arena` 调用，不携带编码会话历史或工具。

## 模型体验

### 生成预览请求

#### 模型看到什么

只有用户手动选择的单个路由会收到一段文本提示词，其中包含写作模式、相关结构化记忆、作品梗概、时间线、大纲、章节标题与摘要、当前正文、可选的选中文字和用户指令。助手对话还会收到最近十条写作消息和当前引用原文。它不会收到编码会话历史或工具。提示词要求遵守已确认的故事记忆。

#### Token 影响

只有用户点击“生成预览”或发送助手消息时才创建一次请求提示词。结构化记忆会按当前问题的关键词选择，并带有有界的兜底上下文。故事上下文、最近对话和正文合计限制为 16,000 个字符，响应预算为 4,096 tokens。

#### KV Cache 影响

写作提示词由持续变化的本地作品状态组装，因此不会成为跨请求稳定复用的前缀。本包不会向编码代理的持久系统提示词添加内容。

## 已知限制与延期工作

- 作品目前保存在浏览器本地存储中，不会在多台设备之间同步。
- 当前只支持 Markdown 导出；导入、DOCX/EPUB 导出、版本历史和跨文档搜索暂缓。
- 生成是非流式的，并且只使用一个明确选择的路由。提供方失败会直接显示，绝不自动回退。
- 地图记忆目前是语义地图（地点节点与命名连接），不是图形画布或地理渲染器。
